1. Overview

Sportza uses Razorpay for payments in INR. It supports both booking payments and batch payments (training). Multiple payment methods are supported.

4. Payment Flow

  1. User selects payment method on booking/batch summary
  2. Frontend calls POST /api/payments/create-order with booking/batch ID
  3. API creates Razorpay order and returns orderId, amount, key
  4. Frontend opens Razorpay Checkout (modal/redirect)
  5. User completes payment on Razorpay
  6. Razorpay returns payment_id and signature to frontend
  7. Frontend calls POST /api/payments/verify with payment_id + signature
  8. API verifies signature, updates booking/batch status, creates Payment record
  9. User sees confirmation screen

6. Webhook

Configuration: Razorpay sends events to /api/webhooks/razorpay. Events include payment.captured, payment.failed, refund.created.

Signature verification: HMAC-SHA256 using webhook secret; reject invalid payloads.

Idempotent updates: Use payment_id or event ID to avoid duplicate processing.

7. Security

  • PCI DSS: Razorpay handles card data; we never store raw card details
  • Secrets management: API keys and webhook secret in env vars / vault
  • Signature verification: All webhook payloads verified before processing
  • Idempotency: Payment confirmations and refunds processed once

8. Batch Fee Payments

Batch fee payments (trainer enrollments) follow the same Razorpay gateway pattern. The BatchPayment model captures commission split:

FieldDescription
platformCommissionPercentCommission rate agreed at batch onboarding
platformCommissionAmountAmount kept by platform
trainerNetAmountAmount going to trainer
validationStatusWhether offline/online payment has been confirmed

API: POST /api/batches/:id/payments — records a batch fee payment. GET /api/batches/:id/payments — reads payments for a batch.

9. Monthly Reports

Commission data is aggregated into monthly settlement reports:

  • GET /api/reports/venues/:venueId/monthly — venue net revenue and platform commission
  • GET /api/reports/trainers/me/monthly — trainer net revenue and commission
  • GET /api/reports/platform/monthly — platform-wide (admin; optional breakdown=venue,trainer)
