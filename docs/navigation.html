1. Philosophy

Booking = core revenue; Open Play + Stats = retention. Navigation is designed to surface booking quickly while keeping social and competitive features one tap away.

2. Primary Navigation

Single 5-tab BottomNav: Home, Venues, Matches, Train, Profile. The old role-switching nav has been replaced by a single unified nav with role-specific routes (e.g. /trainer/*, /venue-owner/*) for trainers and venue owners.

5. Auth Flow

Uses Auth0 with:

  • Google SSO — One-tap login
  • Email OTP — Passwordless
  • Magic Link — Email-based verification

6. Frontend Structure

38 pages, with:

  • MainLayout — Wraps authenticated app with BottomNav
  • AuthLayout — Wraps login/register
  • AuthGuard — Protects routes requiring authentication

7. Secondary Patterns

  • Stack — Standard push/pop navigation
  • Modal — Overlays for quick actions
  • Full-screen — Payment, booking confirmation

8. UX Rules

  • Max 3 taps to book
  • Logical back navigation
  • No deep nesting >4 levels
  • Stats accessible in 1 tap
